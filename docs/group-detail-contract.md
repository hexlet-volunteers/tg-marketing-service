# Контракт детальной страницы подборки

## GET `/collections/<slug>/`

Публичный endpoint детальной страницы подборки.

Endpoint возвращает Inertia-страницу с компонентом `GroupDetail`.

Backend находит подборку по `slug` и передаёт данные для отображения страницы, включая информацию о подборке, список каналов и данные для управления подборкой.

## Структура props

Компонент `GroupDetail` получает следующие свойства:

| Поле | Тип | Описание |
|---|---|---|
| `header` | `object` | Данные для отображения заголовка подборки |
| `group` | `object` | Полные данные подборки |
| `channels` | `array` | Список каналов для отображения |
| `auto_category` | `string \| null` | Категория автоматической подборки |
| `add_form` | `object \| null` | Форма добавления каналов |
| `is_owner` | `boolean` | Признак того, что текущий пользователь является владельцем подборки |

## Заголовок подборки (`header`)

| Поле | Тип | Описание |
|---|---|---|
| `name` | `string` | Название подборки |
| `description` | `string` | Описание подборки |
| `gradient_key` | `string` | Ключ для выбора градиента заголовка |
| `is_editorial` | `boolean` | Признак редакционной подборки |
| `curator` | `string \| null` | Имя пользователя, выступающего куратором подборки |
| `channel_count` | `integer` | Количество каналов в подборке |
| `category` | `string \| null` | Категория автоматической подборки |

### Формирование градиента

Поле `gradient_key` формируется на backend по идентификатору подборки:

`collection-{group.pk}`

### Куратор

Поле `curator` содержит имя пользователя, если у подборки назначен куратор.

Если куратор не назначен, возвращается `null`.

### Категория

Для автоматической подборки поле `category` содержит категорию, заданную в `AutoGroupRule`.

Для обычной подборки возвращается `null`.

## Каналы (`channels`)

Каждый элемент массива `channels` представляет собой данные одного канала.

| Поле | Тип | Описание                                             |
|---|---|------------------------------------------------------|
| `title` | `string` | Название канала                                      |
| `username` | `string` | Имя пользователя или идентификатор канала в Telegram |
| `avatar` | `string` | пустая строка                                        |
| `subscribers` | `integer` | Количество подписчиков                               |
| `average_views` | `integer` | Среднее количество просмотров                        |
| `category` | `string` | Категория канала                                     |
| `country` | `string` | Код страны канала                                    |

### Формирование списка каналов

Для обычной подборки возвращаются каналы, связанные с ней через Many-to-Many-связь.

Для автоматической подборки возвращаются каналы, категория которых совпадает с категорией, заданной в `AutoGroupRule`.

Количество каналов в `header.channel_count` соответствует количеству каналов в `channels`.

## Права доступа

### `is_owner`

Поле определяет, является ли текущий авторизованный пользователь владельцем подборки.

- `true` — текущий пользователь является владельцем.
- `false` — пользователь не является владельцем или не авторизован.

### `add_form`

Форма добавления каналов передаётся только владельцу обычной подборки.

- Для владельца обычной подборки передаётся объект формы.
- Для автоматической подборки возвращается `null`.
- Для пользователя, который не является владельцем, возвращается `null`.
- Для анонимного пользователя возвращается `null`.

## Обработка ошибок

Если подборка с указанным `slug` не существует, backend возвращает HTTP 404.

## Пустая подборка

Если подборка не содержит каналов:

- `channels` возвращается как пустой массив `[]`;
- `header.channel_count` равен `0`.
