# Контракт каталога подборок

## GET `/collections/`

Публичный endpoint каталога подборок.

Endpoint возвращает Inertia-страницу с компонентом `Collections`.

### Query-параметры

Endpoint поддерживает следующие параметры:

* `q` — необязательный поисковый запрос. Фильтрует подборки по `name` и `description`;
* `country` — необязательный код страны. Оставляет только подборки, содержащие каналы указанной страны;
* `category` — необязательная категория. Оставляет только подборки, относящиеся к указанной категории.

Пример:

```text
/collections/?q=игры&country=RU&category=Игры
```

Параметры фильтрации не изменяют структуру ответа.

## `collections`

`collections` содержит полный список подборок, соответствующих текущим фильтрам.

Подборки сортируются:

1. по `order` по возрастанию;
2. при одинаковом `order` — по `name` по возрастанию;
3. при одинаковых `order` и `name` — по `id` по возрастанию.

Каждая подборка содержит:

* `id` — идентификатор подборки;
* `name` — название;
* `slug` — URL-идентификатор;
* `description` — описание подборки или пустая строка;
* `is_editorial` — признак редакторской подборки;
* `curator` — username куратора или `null`;
* `channel_count` — количество каналов в подборке;
* `cover` — URL обложки или пустая строка;
* `gradient_key` — стабильный ключ градиента для оформления подборки.

## `featured`

`featured` содержит не более трёх подборок из текущего отфильтрованного каталога.

Для формирования `featured` используется следующий порядок:

1. редакторские подборки (`is_editorial=true`) идут первыми;
2. внутри каждой группы — по `order` по возрастанию;
3. при одинаковых `is_editorial` и `order` — по `id` по возрастанию.

Итоговый порядок:

```text
is_editorial DESC → order ASC → id ASC
```

Из полученного списка выбираются первые три подборки.

Если в каталоге меньше трёх подборок, `featured` содержит все доступные подборки.

Подборка из `featured` также присутствует в полном списке `collections`.

## `sections`

`sections` содержит подборки, сгруппированные по категориям каналов.

Каждая секция содержит:

* `title` — название категории;
* `collections` — подборки, относящиеся к данной категории;
* `count` — количество подборок в секции.

Пример:

```json
{
  "title": "Игры",
  "collections": [
    {
      "id": 1,
      "name": "Лучшие игровые каналы",
      "slug": "best-games",
      "description": "Подборка игровых каналов",
      "is_editorial": true,
      "curator": "curator",
      "channel_count": 15,
      "cover": "",
      "gradient_key": "collection-1"
    }
  ],
  "count": 1
}
```

Для обычной подборки категории определяются по категориям связанных каналов.

Для автоматической подборки категория определяется значением `category` связанного `AutoGroupRule`.

Одна подборка может присутствовать в нескольких секциях.

Секции сортируются по названию категории по возрастанию.

Секции формируются для подборок, соответствующих текущим фильтрам.

## `filters`

`filters` содержит состояние применённых фильтров и доступные значения для элементов управления на frontend.

Структура:

* `q` — текущее значение поискового запроса или `null`;
* `country` — текущая выбранная страна или `null`;
* `category` — текущая выбранная категория или `null`;
* `country_options` — доступные значения страны с учётом `q` и `category`;
* `category_options` — доступные категории с учётом `q` и `country`.

Например:

```json
{
  "q": "игры",
  "country": "RU",
  "category": "Игры",
  "country_options": ["DE", "RU"],
  "category_options": ["Игры", "Киберспорт"]
}
```

Текущие значения `q`, `country` и `category` отражают параметры текущего запроса.

### `country_options`

`country_options` формируется с учётом:

* `q`;
* `category`.

Текущий `country` при формировании `country_options` игнорируется.

Таким образом, список стран показывает значения, доступные при сохранении остальных активных фильтров.

### `category_options`

`category_options` формируется с учётом:

* `q`;
* `country`.

Текущий `category` при формировании `category_options` игнорируется.

Таким образом, список категорий показывает значения, доступные при сохранении остальных активных фильтров.

Для обычных подборок при формировании options учитываются каналы из `Group.channels`.

Для автоматических подборок учитываются каналы, соответствующие категории из `AutoGroupRule`.

## Фильтрация по `q`

Параметр `q` применяется к названию и описанию подборки.

Подборка попадает в результат, если значение `q` содержится в одном из полей:

* `name`;
* `description`.

Поиск выполняется без учёта регистра.

Пример:

```text
/collections/?q=игры
```

Возвращает подборки, содержащие `игры` в названии или описании.

## Фильтрация по `country`

Параметр `country` ограничивает каталог подборками, в которых присутствует хотя бы один канал указанной страны.

Для обычной подборки проверяется `country` каналов, связанных через `Group.channels`.

Для автоматической подборки проверяется `country` каналов, категория которых соответствует `AutoGroupRule.category`.

Пример:

```text
/collections/?country=RU
```

Возвращает только подборки, содержащие соответствующие российские каналы.

## Фильтрация по `category`

Параметр `category` ограничивает каталог подборками, относящимися к указанной категории.

Для обычной подборки проверяется наличие связанного канала с указанной категорией.

Для автоматической подборки категория определяется значением `AutoGroupRule.category`.

Пример:

```text
/collections/?category=Игры
```

Возвращает только подборки, относящиеся к категории `Игры`.

Фильтр `category` применяется совместно с `q` и `country`, если они переданы.

Например:

```text
/collections/?q=игры&country=RU&category=Игры
```

Возвращает подборки, одновременно соответствующие поисковому запросу, стране и категории.

## `channel_count`

`channel_count` — количество каналов подборки.

Для обычной подборки количество каналов определяется через M2M-связь `Group.channels`.

Для автоматической подборки количество каналов определяется по категории, указанной в связанном `AutoGroupRule`. Учитываются все `TelegramChannel` с соответствующим значением `category`.

Frontend не определяет способ расчёта `channel_count`: backend возвращает готовое количество.

Расчёт выполняется без N+1-запросов.

## `gradient_key`

`gradient_key` — стабильный ключ для выбора оформления подборки на frontend.

Формируется на backend по идентификатору подборки:

```text
collection-{id}
```

Например:

```text
collection-1
collection-25
collection-142
```

Ключ не зависит от порядка элементов каталога и не изменяется между запросами для одной и той же подборки.

## Пустой каталог

Если после применения фильтров подборок нет, endpoint возвращает успешный Inertia-ответ с пустыми `featured`, `collections` и `sections`.

Например:

```json
{
  "component": "Collections",
  "props": {
    "featured": [],
    "collections": [],
    "sections": [],
    "filters": {
      "q": "несуществующий запрос",
      "country": null,
      "category": null,
      "country_options": [],
      "category_options": []
    }
  },
  "url": "/collections/?q=несуществующий%20запрос"
}
```

## Ограничения endpoint

Endpoint предназначен только для получения данных каталога.

Создание, изменение и удаление подборок через `/collections/` не выполняется.

Для реализации каталога дополнительные миграции не требуются.
